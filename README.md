# Лабораторная работа №5 (frontend)
- Цель работы: Разработка базового SPA на React
- Скриншоты 1-3 Показать три страницы фронтенда с `mock` и вкладкой `network`. Скриншоты 4-5 Показать реализацию изображения по-умолчанию. Скриншоты 6-7 Объяснить код компонентов для фильтрации, передаваемые props, Скриншоты 8-9 все используемые хуки. Скриншоты 10 `Readme` для фронтенда

- Задание: Разработать три страницы фронтенд приложения на `React`, `TS` и подключить его к веб-сервису

## Страницы приложения

В приложении 4 страницы. В ЛР5 работают «Лента» и «Плитка» для гостя: данные берутся из mock-объектов, без бэкенда, БД и S3. Страницы «Добавление» и «Вход» описаны заранее и будут доступны в следующих лабораторных.

### Лента — `/pancreatitis-signs/feed`, `/pancreatitis-signs/feed/:id`

Один признак шкалы Рэнсона на весь экран.

| Элемент | Описание |
|---|---|
| Видео на фоне | видео признака, если поля нет — видео по умолчанию |
| Название | название признака |
| Описание | краткое описание признака |
| Кнопка «еще» | раскрывает полное описание |
| Лайк с числом | количество лайков |
| Кнопка далее | переход к следующему признаку |
| Порог | пороговое значение признака |
| Этап | «При поступлении» или «Через 48 часов» |

### Плитка — `/pancreatitis-signs/grid`

Все признаки карточками в две колонки.

| Элемент | Описание |
|---|---|
| Ползунок | максимальное пороговое значение (от 0 до 350) |
| Кнопка фильтра | показывает признаки с порогом не больше выбранного |
| Карточка | фото (или изображение по умолчанию), название, этап, лайки; по нажатию открывает признак в ленте |

### Добавление — `/pancreatitis-signs/add`

Создание и публикация карточки признака. Доступна создателю, в ЛР5 пункт меню неактивен.

| Элемент | Описание |
|---|---|
| Выбор фото | загрузка изображения признака |
| Выбор видео | загрузка вертикального видео признака |
| Поле «Тема / Критерий» | название признака |
| Кнопка «Далее» | создаёт черновик с названием, фото и видео |
| Поле «Описание» | описание признака (после создания черновика) |
| Поле «Этап оценки» | «При поступлении» или «Через 48 часов» |
| Поле «Пороговое значение» | пороговое значение признака |
| Кнопка «Опубликовать» | публикует признак и открывает его в ленте |

### Вход — `/login`

Аутентификация и регистрация. Доступна гостю, в ЛР5 пункт меню неактивен.

| Элемент | Описание |
|---|---|
| Поле «Логин» | логин пользователя |
| Поле «Пароль» | пароль пользователя |
| Кнопка «Войти» | вход в систему, после входа открывается плитка в интерфейсе создателя |
| Кнопка «Зарегистрироваться» | регистрация нового пользователя и вход |
