## Страницы приложения

Пользователь — гость. Данные берутся из mock-объектов, без бэкенда, БД и S3.

### Лента — `/pancreatitis-signs/feed`, `/pancreatitis-signs/feed/:id`

Один признак шкалы Рэнсона на весь экран.

| Элемент | Описание |
|---|---|
| Видео на фоне | видео признака, если поля нет — видео по умолчанию |
| Название | название признака |
| Описание | краткое описание признака |
| Кнопка «еще» | раскрывает полное описание |
| Лайк с числом | количество лайков |
| Кнопка далее | переход к следующему признаку |
| Порог | пороговое значение признака |
| Этап | «При поступлении» или «Через 48 часов» |

### Плитка — `/pancreatitis-signs/grid`

Все признаки карточками в две колонки.

| Элемент | Описание |
|---|---|
| Ползунок | максимальное пороговое значение (от 0 до 350) |
| Кнопка фильтра | показывает признаки с порогом не больше выбранного |
| Карточка | фото (или изображение по умолчанию), название, этап, лайки; по нажатию открывает признак в ленте |
